진단 판단 원칙

Falcon Log의 첫 번째 원인 후보와 후속 Remapping 실패를 분리합니다. SN300375 검증 사례는 참고 증거이며, 다른 SN의 설정을 자동 변경하지 않습니다. PCB 교체는 별도 하드웨어 확인 전까지 권고하지 않습니다.

로그·CSV를 선택하고 분석을 시작하면 원인 후보별 증거, 점검 부위, 추가 검증을 표시합니다.

1. 사진 촬영 및 오류 인식

iPhone SE 이상에서 카메라/사진보관함을 선택해 Falcon System Events를 촬영하세요. EFFECT·DESCRIPTION·MORE INFORMATION 위주로 결과를 추출합니다.

로그 내용은 브라우저 안에서만 처리합니다. 외부 서버에 업로드하지 않습니다. ZIP 파일은 브라우저에서 자동 압축 해제합니다. SN별 데이터는 현재 브라우저 내부에 저장됩니다.

사진으로 오류 및 Alignment 분석

iPhone SE 이상: 카메라로 촬영하거나 사진 보관함에서 선택하세요. 사진 내 화면 글자를 OCR로 추출하여 기존 로그 분석 엔진과 비교합니다.

사진 OCR은 최초 이용 시 인터넷 연결을 통해 Tesseract.js 및 언어 모델을 가져옵니다. 사진 파일 자체는 이 앱이 서버에 업로드하지 않지만 외부 라이브러리를 불러오므로 온라인 환경에서 보안 정책을 확인하세요. HEIC는 브라우저가 디코딩 가능한 경우에만 지원합니다. 사진 분석은 화면 속 텍스트만 다루며 물리적 손상 판단이나 PCB 교체 확정은 하지 않습니다.

사진을 선택하거나 텍스트를 입력하세요.
